# quizlet

## Run the study hub

Open the [study hub SVG](https://cdn.jsdelivr.net/gh/kkudzu/quizlet@8e96058186cf53a09898021790d41745aaac33a4/quiz1.svg) directly in a modern browser. GitHub Raw applies a sandbox policy that prevents the SVG's launch button from running, so use the jsDelivr URL for the SVG itself. The SVG fetches its larger model parts from GitHub Raw. It launches the full HTML app in a new `about:blank` tab; no local download, separate server, backend, or proxy is needed. The app starts with no preloaded modules; paste or upload a Quizlet set to add one. When publishing future changes, update the commit in this URL to the published revision.

Every card is interpreted by the pinned SmolLM2 model locally in the browser; no local heuristics choose or infer answers. The CPU ONNX model and tokenizer are split into small, integrity-checked files and fetched from GitHub Raw when a study set is added; no Hugging Face connection or local model download is needed. Model inference runs in a background Web Worker so the app stays responsive while cards are processed one at a time. If an answer is missing or cannot be matched to the source, the model gets one retry asking for the complete answer line or choice. Every source card is kept even when the model cannot produce a valid highlight. The app only highlights model-selected text that appears in the original card, preserving its wording and line breaks; for fill-in cards, a selected answer printed on its own line is inserted inline into the blank. Model-assigned answer categories use distinct colors for rules, actions, terms, numbers, warnings, definitions, and facts. Model-generated related search terms are indexed during card parsing, so concept search is immediate and needs no extra AI request. The bundled SmolLM2 files are Apache-2.0 licensed; the model source and license are included in the source archive.

Transformers.js and the ONNX Runtime WebAssembly engine are loaded from jsDelivr, while the model parts are loaded from GitHub Raw. Internet access to `cdn.jsdelivr.net` and `raw.githubusercontent.com` is required for AI. The model is assembled and unpacked in browser memory for inference. The interface uses JetBrains Mono, a minimal neutral palette, and restrained Radicle Garden-inspired colored highlights.

`quiz1.svg` is a small launcher that opens the app in a new `about:blank` tab. Click **Open study hub**; if your browser blocks pop-ups, allow them for this page and try again. After cloning, install Git LFS and run `git lfs pull` to check out the source model archive. After changing the app or model, regenerate the SVG and its GitHub Raw model parts with `python3 build_svg.py`. The generated `quiz1.svg` is kept below GitHub's ordinary file-size limit, and the model is split into 10 MiB SHA-256-verified files.
